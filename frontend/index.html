How it works

4 MODULES
📚

Knowledge base

29 IF–THEN rules for 9 diseases, each carrying a certainty factor in the MYCIN tradition. Editable without touching the engine code.

knowledge_base.py
⚙️

Inference engine

Forward chaining fires every matching rule, then certainty factors are combined with classic CF algebra to rank the hypotheses.

inference_engine.py
📊

ML prior

A from-scratch Naive Bayes trained on the original Kaggle dataset (4,920 records, 41 diseases) re-ranks the rule-supported hypotheses.

ml_prior.py
🛡️

Safety gate

Confidence below threshold? The system abstains and sends you to a doctor — the rule base gates, ML never diagnoses alone.
